# Служебные записки по стандартам

Приложение для специалиста по биобезопасности: собирает служебную или докладную записку
в настоящем формате Word (.docx) — с шапкой организации, блоком адресата, ссылками на пункты
загруженных стандартов и приложением с фотофиксацией. Текст пишет ИИ строго по загруженным
документам, без выдуманных номеров пунктов.

## Файлы

| Файл | Для чего |
|------|----------|
| `dist/sluzhebki_app.html` | Готовое приложение. Один файл, работает с диска, без интернета (кроме запросов к ИИ). Требует ключ Anthropic API. |
| `dist/sluzhebki_artifact.html` | Версия-ссылка: ИИ работает встроенно, ключ не нужен. |
| `src/app.html` | Исходник приложения с метками `{{VENDOR}}`, `{{LOGO}}`, `{{AI_ADAPTER}}`. |
| `src/ai/standalone.js` | Доступ к ИИ через ключ Anthropic API. |
| `src/ai/artifact.js` | Доступ к ИИ через среду выполнения артефакта. |
| `vendor/mammoth-jszip.html` | Библиотека mammoth.js — чтение .docx (стандарты и образцы). |
| `assets/logo.b64` | Логотип АО «УКПФ» из образца, зашит в приложение по умолчанию. |
| `build.py` | Сборка: `python3 build.py` → файлы в `dist/`. |

## Как пользоваться

1. **Организация** — один раз: название, вторая строка шапки, логотип, шрифт, ваши должность и фамилия.
   Там же справочники: адресаты (кому пишем) и сотрудники с подрядными организациями.
2. **Стандарты** — загрузите СТ-УК, БиС-01 и остальные документы в .docx. Они хранятся только
   в браузере, в запрос к ИИ уходят лишь отмеченные вами фрагменты.
3. **Записка** — выберите адресата и нарушителя из справочников, опишите нарушение своими словами,
   нажмите «Найти пункты» и отметьте подходящие, затем «Составить записку».
4. **Готовый документ** — правьте текст, при необходимости «Вычитать текст ИИ», затем
   «Скачать Word (.docx)».

Структура текста переключается на вкладке «Записка»:
* **Как в образцах** — сплошной текст: довожу до сведения → факт → пункты стандарта → вывод → просьба.
* **Расширенная** — с блоками «Корневая причина», «Корректирующие мероприятия», «Предлагаемые меры»
  и сроком обратной связи.

## Разметка текста записки

| Строка | Во что превращается в Word |
|--------|---------------------------|
| обычная строка | абзац по ширине с красной строкой |
| `- текст` | пункт перечня с тире |
| `1. текст` | нумерованный пункт |
| `## Заголовок` | подзаголовок полужирным |

Шапка организации, блок адресата, строка «Дата / Подпись», перечень приложений и фотофиксация
добавляются в документ автоматически из полей формы.

## Где что хранится

* Настройки, справочники, образцы, поля формы — `localStorage` браузера.
* Тексты стандартов и фотографии — `IndexedDB` (стандартов бывает много, в localStorage они не помещаются).
* Ключ Anthropic API — только в `localStorage` этого браузера, отправляется напрямую в api.anthropic.com.

Данные привязаны к браузеру и профилю: в другом браузере или после очистки данных сайта их не будет.

## Формат Word

Документ собирается как настоящий OOXML-пакет: `word/document.xml`, `word/header1.xml`
с таблицей колонтитула (логотип + название организации с линией), `word/styles.xml`,
изображения в `word/media/`. Упаковка в ZIP — собственная реализация без сжатия (`ZIP.make`),
внешних библиотек для этого не требуется.

Имя файла транслитерируется латиницей: браузеры теряют кириллицу в атрибуте `download`
и сохраняют файл без расширения.

## Сборка

```
python3 build.py
```
