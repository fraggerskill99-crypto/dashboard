# Aurum SMC — анализ золота (XAU/USD)

Приложение для телефона и компьютера: живой график золота с разметкой Smart Money Concepts
и Malaysian SNR, сигналы по модели A+, бэктест на истории, график TradingView и индикатор
Pine Script для самого TradingView.

## Что делает

| Блок | Что считает |
|------|-------------|
| Структура | свинги (фракталы), BOS и CHoCH по закрытию свечи |
| Ордер-блоки | последняя противоположная свеча перед импульсом, сломавшим структуру |
| FVG | имбалансы из трёх свечей (гэпы выходных не учитываются) |
| Ликвидность | равные максимумы/минимумы, PDH/PDL, азиатская сессия, свинги; снятие = тень за уровень и возврат закрытием |
| SNR | Malaysian SNR по закрытиям старшего ТФ: A — пик, V — впадина; свежие (без касания тенью) и флип-уровни |
| Премиум/дискаунт | положение цены в диапазоне последних свингов старшего ТФ |
| Killzone | Лондон 07–10 и Нью-Йорк 12–15 UTC |

### Модель сигнала A+

1. Снятие ликвидности против будущей сделки.
2. Слом структуры (CHoCH/BOS) в сторону сделки не позже 30 свечей после снятия.
3. Лимитный вход в ордер-блок импульса (середина, край OB или край FVG), стоп за экстремумом снятия, тейк = RR × риск.
4. Оценка конфлюэнса 0–12: тренд старшего ТФ +3, сила снятой ликвидности +1/+2, CHoCH +1, FVG в импульсе +1,
   дискаунт/премиум +2, свежий SNR в зоне входа +2, killzone +1. Сигнал выдаётся от порога (по умолчанию 8).

### Бэктест и винрейт

Вкладка «Бэктест» прогоняет ту же модель по загруженной истории (одна позиция за раз; стоп и тейк
в одной свече — убыток) и показывает винрейт, итог в R, PF и просадку для каждого порога оценки и для
разных RR. Кнопка «Поставить порог» выбирает порог с лучшим винрейтом при ≥ 8 сделках.
Порог подбирается на той же истории, поэтому вперёд результат обычно хуже — это инструмент, а не гарантия.

## Источники котировок

* **PAXG/USDT, Binance** — бесплатно, без ключа. Токен на физическом золоте, идёт вровень с XAU/USD; свечи выходных вырезаются.
* **XAU/USD спот, Twelve Data** — нужен бесплатный ключ с twelvedata.com (хранится только в браузере). Обновление раз в 5 минут.
* **CSV** — экспорт данных графика из TradingView (столбцы time, open, high, low, close).

## Как поставить на телефон

1. Выложить папку `gold/` на любой HTTPS-хостинг. Проще всего GitHub Pages: Settings → Pages →
   Deploy from a branch → ветка с этим кодом, папка `/ (root)`. Адрес: `https://<логин>.github.io/dashboard/gold/`.
2. Открыть адрес на телефоне: Android (Chrome) — меню → «Установить приложение»;
   iPhone (Safari) — «Поделиться» → «На экран Домой».

Без хостинга: `python3 build.py` соберёт `dist/aurum_smc.html` — один файл, открывается в браузере.

## Индикатор для TradingView

`smc_snr.pine` — та же логика на Pine Script v5: зоны, BOS/CHoCH, снятия ликвидности, SNR старшего ТФ,
сигналы с входом/стопом/тейком и оповещения. Pine Editor → вставить → «Добавить на график»;
затем «Добавить оповещение» → условие «Aurum SMC + SNR» для пушей на телефон.
