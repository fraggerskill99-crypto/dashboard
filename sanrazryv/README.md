# Санитарный разрыв

Приложение для телефона и ПК: загружаете графики санитарного разрыва (Excel, как их составляет цех),
и на выбранный день видно — в двух разделах:

* **Возраст птицы** — корпуса с птицей и сколько дней прошло от заселения (код ЗС), по возрасту или по цехам;
* **Процессы** — колонки процессов — освобождение, ремонт, мойка, приёмка, дезинсекция, дезинфекция, засыпка,
  газация, побелка, септик, обработка дорог, подготовка, заселение — в каких цехах и корпусах они идут;
* **Пустые, без работ** — корпуса в санитарном разрыве без работ в этот день.

Вкладка «Корпуса» — состояние каждого корпуса по цехам и его история по дням.

| Файл | Для чего |
|------|----------|
| `app.html` | Исходник приложения. |
| `vendor/xlsx.full.min.js` | SheetJS 0.18.5 — чтение Excel (лицензия Apache-2.0, `vendor/xlsx.LICENSE`). |
| `build.py` | Сборка: `dist/www` (веб/Android/Windows) и `dist/sanrazryv.html` (один файл). |
| `desktop/` | Оболочка Electron для Windows. |

Сборка APK и .exe — `.github/workflows/sanrazryv-app.yml`, выпуск **sanrazryv-app**:
https://github.com/fraggerskill99-crypto/dashboard/releases/tag/sanrazryv-app

## Как читается график

* Строка заголовка — «Цех | Этаж | даты месяца».
* Цех берётся из первого столбца; новый цех начинается, когда номер этажа/корпуса повторяется.
* Ячейка может содержать несколько кодов через `/` или `\` (например `ОС/ОЧН`, `ДЗ/ГФ`).
* Расшифровка кодов — из условных обозначений под таблицей.
* Возраст птицы: день заселения — 0-й день (на следующий день птице 1 день); при заселении в несколько дней —
  от первого дня ЗС. Оба правила можно поменять в настройках. Санитарный разрыв — от дня освобождения (ОС).
* Корпус без событий в загруженных графиках считается занятым птицей с неизвестной датой заселения.
* После освобождения (ОС) возраст не считается. Если между заселением и датой нет графика (дата позже графиков
  или пропущен месяц), возраст не показывается — освобождение могло быть.
* Названия площадок сводятся без пробелов и латиницы: «БП13», «БП 13», «бп 13» — одна площадка.

Графики хранятся только на устройстве, в репозиторий не попадают.

**Программа для Windows** создаёт папку `Документы\График санитарного разрыва` и при каждом запуске
подхватывает из неё все файлы Excel, а при появлении нового или изменённого файла обновляется сама.
Загруженное вручную сохраняется в файл `sanrazryv-data.json` в папке данных программы
(`%APPDATA%\Санитарный разрыв`), поэтому не пропадает после перезапуска (`desktop/main.js`, `desktop/preload.js`).
