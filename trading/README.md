# Уровни и сигналы

Помощник для торговли от уровней (по умолчанию — золото XAUUSD). Один файл
`dist/trading_app.html`: скачай и открой в Chrome двойным кликом.

Что делает:

- сам находит уровни на старшем ТФ: свинги с несколькими касаниями, максимум/минимум
  вчерашнего дня, круглые цены; свои уровни ставятся кликом по графику;
- по закрытым свечам ищет три сетапа:
  - **отбой фитилём** — тень коснулась уровня, свеча закрылась обратно → разворот;
    тень проколола уровень и вернулась → **ложный пробой** (сильнее);
  - **пробой** — закрытие за уровнем сильным телом → «Пробой ▲ → BUY» / «Пробой ▼ → SELL»,
    идём по направлению пробоя; **ретест** — возврат к уровню и удержание → второй, лучший вход;
  - **ловушка** — пробой не удержали, закрытие обратно → вход в обратную сторону;
- по умолчанию ждёт подтверждающую свечу; стоп — за уровнем/тенью, тейк — у следующего уровня;
- оценивает сигнал (сила уровня, тренд старшего ТФ по EMA50, объём, прибыль/риск) и
  помечает слабые «пропустить»;
- отмечает на графике свечные модели (молот, пин-бар, поглощение, утренняя/вечерняя звезда)
  у уровней и добавляет их в оценку сигнала;
- кнопка «TradingView OANDA» показывает настоящий график OANDA:XAUUSD для сверки;
- считает лот от депозита и риска, пищит и шлёт уведомление при сильном сигнале;
- показывает, как сработали сигналы на истории (тейк/стоп).

Источник цены золота («Настройки»):

- **OANDA** — свечи XAU_USD прямо из OANDA, цена 1-в-1 как на графике TradingView OANDA.
  Нужен бесплатный токен демо-счёта (oanda.com → Manage API Access → Generate).
- **Twelve Data** — XAU/USD с бесплатным ключом, обновление раз в 2 минуты.
- **Биржи + подгонка** (по умолчанию, без ключей) — свечи Binance/Bybit/OKX, сдвинутые под живую
  спот-цену XAUUSD (Swissquote). Если котировка недоступна — введи цену брокера и нажми «Сверить».

Есть режим CSV (экспорт графика из TradingView) и демо без интернета.

Сборка: `python3 build.py` (вставляет Lightweight Charts 4.1.3 из `vendor/`).

Это помощник, а не гарантия прибыли: проверь на демо-счёте.
