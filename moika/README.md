# Качество мойки

Дашборд качества мойки УКПФ (автор — Турсынгалиев Б.) в виде приложения для телефона и ПК.
Всё, что было в дашборде, сохранено: обзор, сравнение по турам, категории несоответствий,
график СР · ПР/Р, чек-лист, слайд для презентации. Добавлено:

* **Средний балл за месяц** — первым на «Обзоре». Считается сам по всем оценкам месяца:
  Выращивание (акты приёма мойки, норма 8), Инкубаторий (норма 8) и ЗПП (шкала 0–5, коридор 3–5);
  изменение к прошлому месяцу, сколько оценок и какая доля ниже 8. Текущий месяц помечен «идёт».
  Ниже — Выращивание по зонам за последние 12 месяцев. Таблица выгружается в Excel (CSV).
* **Данные на устройстве.** В само приложение данные не вшиты. Один раз загрузите старый файл
  дашборда (.html) — из него переносятся все акты с марта 2025, сверки ПР/Р, баллы Инкубатория и ЗПП,
  подписи фото. Новые акты (.xlsx) добавляются как раньше и тоже сохраняются.
* Сегодняшняя дата берётся из устройства (в исходном файле была зашита 02.08.2026).

| Файл | Для чего |
|------|----------|
| `base.html` | Исходный дашборд без данных. |
| `addon.html`, `addon.css`, `addon.js` | Средний балл по месяцам, загрузка и сохранение данных. |
| `build.py` | Сборка: `dist/www` (веб/Android/Windows) и `dist/moika.html` (один файл). |
| `desktop/` | Оболочка Electron для Windows. |
