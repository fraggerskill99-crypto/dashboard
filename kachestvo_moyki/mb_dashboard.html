Акт мойки → обновляет «Мойка по турам». Журнал МБ → обновляет «Смывы по корпусам» и «Вода по корпусам».
Про журнал МБ: «Свод» (.xlsx) читается прямо в браузере — распаковка и разбор идут кусками, чтобы не упереться в лимит памяти на файле такого размера; это может занять около минуты, окно не зависает, просто ждите. .csv (как раньше, CSV UTF-8) тоже по-прежнему работает. Хронология обнаружений (даты/точки отбора) и главный график по-прежнему обновляю вручную.
«Привязать файл» запоминает файл на этом устройстве в этом браузере (Chrome/Edge) — при следующем открытии дашборда и по кнопке «Обновить» данные подтянутся из него автоматически, без повторной загрузки. Если браузер не поддерживает эту функцию (Firefox/Safari), кнопка скрыта — используйте разовую загрузку.
