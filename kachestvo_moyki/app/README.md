# Приложение «Качество мойки — УКПФ» (ПК и Android)

Три дашборда во вкладках одного окна:

| Вкладка | Исходник |
|---------|----------|
| 🧽 Качество мойки | `../dashboard_kachestvo_moyki.html` |
| 🧫 NOK-дашборд | `../nok_dashboard.html` |
| 🔬 Мойка и МБ | `../mb_dashboard.html` |

Вкладки открываются с одного адреса, поэтому «Мойка и МБ» берёт фото/видео и баллы мойки
из «Качества мойки»: блок **«Обнаружения МБ и фотофиксация мойки по корпусу — в динамике»** —
по корпусу с обнаружениями МБ график (баллы моек, обнаружения, дни с фото) и лента по датам:
мойки с баллом и миниатюрами фото/видео, обнаружения (патоген, точки отбора); мойка перед
обнаружением выделена. Клик по миниатюре — фото/видео на весь экран.

## Как получить

Выпуск **kachestvo-moyki-app**: https://github.com/fraggerskill99-crypto/dashboard/releases/tag/kachestvo-moyki-app

- `kachestvo-moyki-setup.exe` — установщик для Windows (ярлык на рабочем столе и в «Пуске»);
- `kachestvo-moyki-portable.exe` — Windows без установки;
- `kachestvo-moyki.apk` — Android: файлы загружаются кнопками, выгрузки открывают окно «Поделиться»,
  папок с фото/видео на телефоне нет;
- `kachestvo_moyki.html`, `nok_dashboard.html`, `moyka_i_mb.html` — каждый дашборд отдельным файлом для Chrome/Edge.

Собирает GitHub Actions (`.github/workflows/build-windows-app.yml`) при каждом изменении в `kachestvo_moyki/`.
Файлы не подписаны сертификатом: при первом запуске Windows может показать «Система Windows
защитила ваш компьютер» → **Подробнее → Выполнить в любом случае**.

## Папка «Данные» и SharePoint (ПК)

`Документы\Качество мойки\Данные` подключается ко всем вкладкам сама — без окна выбора папки:

- **Качество мойки** — фото/видео (`ГГГГ-ММ-ДД\Корпус\…` на любой глубине), презентации `.pptx`
  (Выращивание и залы Инкубатория), акты Excel по имени файла: «акт/мойк/приём» — приёмка мойки,
  «инкуб» — Инкубаторий, «зпп» — ЗПП, «график/ПР-Р» — график санразрыва;
- **Мойка и МБ** — самый свежий Свод/журнал МБ и акт приёма мойки;
- **NOK-дашборд** — самый свежий `.xlsx` со словом «Свод».

**Автоматически:** при первом запуске приложение само подключает папку УКПФ в SharePoint и
открывает вход Microsoft — войти один раз рабочей учётной записью. Дальше папка скачивается в
`Данные\SharePoint\<папка>` и докачивает только новое: при запуске, каждые 30 минут и по **F5**.
Если вход истёк, окно входа откроется само (при запомненной учётной записи — даже не появится).
Ещё папки — меню **SharePoint → Подключить папку по ссылке…**, список — «Подключённые папки…».
Файлы, положенные в «Данные» руками, подхватываются через несколько секунд.

**Папки на компьютере.** Папка отдела в OneDrive
`OneDrive - АО 'AITAS KZ'\Рабочий стол\Департамент Ветеринарии - Отчетность Департамента Ветеринарии\Служба Ветеринарной Санитарии и БиБ\УКПФ`
подключается сама, если она есть на компьютере (видна в «Данных» как «УКПФ (OneDrive)»), и так же —
`OneDrive - АО 'AITAS KZ'\Рабочий стол\Несоответствие еженедельно` (фото/видео и презентации выращивания, «Несоответствия (OneDrive)»). Оттуда берутся акты
выращивания, Инкубатория и ЗПП, Свод МБ, фото/видео и презентации; обновлённый OneDrive файл подхватывается сам.
Другие папки — меню **Файл → Папки на компьютере…**.

Выгрузки (PNG, PowerPoint, Word) сохраняются в `Документы\Качество мойки` — отдельно от «Данных».

## Для разработчика

```
npm install
npm start      # собрать www и запустить
npm run dist   # собрать .exe (на Windows; на Linux нужен wine)
```

- `build-www.js` собирает `www/`: оболочку с вкладками (`www-src/index.html`) и три дашборда;
  в каждый встраивается `www-src/app-bridge.js` (папка «Данные» и `window.desktop` для NOK —
  работает только по адресу `app://`), в `mb.html` — библиотеки из `www-src/vendor/`
  (без интернета); с `--android` — ещё `android/download-shim.js`.
- `main.js` — окно, адрес `app://app/`, папка «Данные», меню; `sharepoint.js` — вход и скачивание
  папок SharePoint (REST API SharePoint с куками входа).
- Править нужно исходные дашборды в `kachestvo_moyki/`, `www/` — собираемый.
