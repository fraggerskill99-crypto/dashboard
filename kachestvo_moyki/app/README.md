# Приложение «Качество мойки — УКПФ» для Windows

Тот же дашборд (`../dashboard_kachestvo_moyki.html`), но в отдельном окне со своим значком —
без браузера, вкладок и адресной строки.

## Как получить

Сборку делает GitHub Actions (APK — на Linux, .exe — на Windows) при каждом изменении в папке `kachestvo_moyki/`
(или вручную: Actions → «Приложение «Качество мойки» для Windows» → Run workflow).
Готовые файлы — выпуск **kachestvo-moyki-app**:
https://github.com/fraggerskill99-crypto/dashboard/releases/tag/kachestvo-moyki-app

- `kachestvo-moyki-setup.exe` — установщик: ярлык «Качество мойки» на рабочем столе и в меню «Пуск»;
- `kachestvo-moyki-portable.exe` — без установки, запускается сразу (удобно на флешке);
- `kachestvo-moyki.apk` — телефон Android: акты загружаются кнопками, выгрузки (PNG, PowerPoint, Excel)
  открывают окно «Поделиться» — сохранить, WhatsApp, Telegram. Привязки папок с фото/видео на телефоне нет;
- `kachestvo_moyki.html` — сам дашборд, открыть в Chrome/Edge двойным щелчком.

Файл не подписан сертификатом, поэтому при первом запуске Windows может показать
«Система Windows защитила ваш компьютер» → **Подробнее → Выполнить в любом случае**.

## Что умеет

- всё, что дашборд в Chrome/Edge: акты, привязка папок с фото/видео и презентациями, выгрузки PNG/PowerPoint;
- привязанные папки, акты и баллы хранятся в профиле Windows и не теряются при очистке браузера;
- выгрузки по умолчанию сохраняются в «Документы\Качество мойки» (меню Файл → Открыть папку с выгрузками);
- окно запоминает размер и масштаб; масштаб — Ctrl + / Ctrl − / Ctrl 0, во весь экран — F11, печать — Ctrl+P;
- ссылки на сайты открываются в обычном браузере.

Папку из SharePoint/Teams подключайте через синхронизацию OneDrive («Синхронизировать» →
«Всегда хранить на этом устройстве») и затем кнопкой привязки папки в дашборде.

## Для разработчика

```
npm install
npm start      # запустить из исходников
npm run dist   # собрать .exe (на Windows; на Linux нужен wine)
```

`copy-dashboard.js` перед запуском и сборкой кладёт свежий `dashboard_kachestvo_moyki.html`
внутрь приложения как `dashboard.html` — править нужно только исходный дашборд.
