# NOK-дашборд

Дашборд микробиологии УКПФ и МПФ (OK/NOK по объектам исследования за неделю) как приложение для ПК и телефона.
Новый «Свод» подхватывается сам, а все недели копятся на устройстве — и те, которых в новой выгрузке уже нет.

* **Недели сохраняются.** Каждый новый «Свод» добавляет недели к сохранённым. Неделя из нового файла заменяет
  сохранённую, только если в ней не меньше проб (выгрузка может начинаться с середины недели).
  Старые недели переносятся один раз из прежнего файла NOK-дашборда (.html) кнопкой «Перенести недели из файла».
  «Копия всех недель» — файл .json для другого компьютера (переносится той же кнопкой).
* **Свод подтягивается сам:**
  * программа для Windows следит за папкой `Документы\NOK-дашборд` (или выбранной кнопкой «Другая папка…»,
    в том числе сетевой) и обрабатывает самый свежий .xlsx, как только он появился или изменился;
    дополнительно проверяет папку раз в минуту;
  * Chrome/Edge на ПК: «Привязать папку со Сводом» — проверка раз в минуту и при возврате на вкладку;
  * телефон (Android/iPhone) читать папки не даёт — там «Свод» загружается кнопкой, недели всё равно сохраняются.
* Даты с ошибкой в годе (1900 и т. п.) недель не создают.

| Файл | Для чего |
|------|----------|
| `base.html` | Дашборд без вшитых данных, с крючками для приложения. |
| `addon.html`, `addon.css`, `addon.js` | Хранение недель (IndexedDB), автообновление, перенос и копия. |
| `build.py` | Сборка: `dist/www` (веб/Android/Windows) и `dist/nok.html` (один файл). |
| `desktop/` | Оболочка Electron для Windows. |
| `icons/` | Иконка (`logo.svg`, PNG — `python3 icons/make_icon.py`). |

Сборка APK и .exe — `.github/workflows/nok-app.yml`, выпуск **nok-app**:
https://github.com/fraggerskill99-crypto/dashboard/releases/tag/nok-app
Веб-версия: https://fraggerskill99-crypto.github.io/dashboard/nok/

Данные проб в репозиторий не попадают — только на устройство.
