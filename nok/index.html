О методике расчёта категорий
Период = неделя по Дата отбора пробы (ISO-неделя, Пн–Вс).
БП — Цех бройлерного производства / Цех выращивания, без бахильных проб.
Инкубатор — Цех инкубации, без помёта.
ЗПП — Производственный цех / склады ЗПП / ОТО ЗПП, без готовой продукции и без Listia-мэппинга (биомэппинг), без посуды/оборудования столовой.
Кормовые компоненты — готовая продукция: комбикорм, мука кормовая.
Входящая сырьё — группа материала «Сырьё» (шрот, зерно, жмых, бобы).
Транспорт — подгруппа «Транспорт» (по всем цехам).
Подстилочный материал — подгруппа «Подстилочный материал» (по всем цехам).
Инкубационное яйцо / ...газация — подгруппы «Яйцо» и «Яйцо инкубационное»; отдельно — точки отбора с упоминанием «фумигация/газация».
МКО — цех по производству мясокостной муки (подгруппа материала «МКО»); столовая сюда не входит и никак не учитывается.
Пробы «до мойки» (в точке отбора написано «до мойки») не учитываются нигде.
Исключено полностью — Колибактериоз, Антибиотикочувствительность выделенных культур, Стрептококки (Энтерококки) в пат. материале (не входят ни в Всего, ни в NOK ни по одной категории).

Категории пересекаются намеренно (как в исходном ручном отчёте): например, «Транспорт» и «Инкубационное яйцо» — сквозные категории, которые также входят в общий итог «Инкубатор».
